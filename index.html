My library

Saved pictures and GIFs appear here, so you can resend them with one tap. They're stored only on this phone.

Tip: install the app (Chrome menu → Add to Home screen), then use Share → Tivoo Studio from your gallery or browser to send a GIF straight here.

Scrolling text

Long text is scrolled in bigger steps so it fits the Tivoo's 60-frame limit. Use Stream live for smooth scrolling of long messages.

Connection help
  1. Turn the Tivoo on and pair it in Android Settings → Bluetooth (it may show up twice: once for audio, once as "Tivoo-light" or similar; pair both).
  2. Open this page in Chrome, tap Connect and pick the Tivoo.
  3. If the Tivoo isn't listed, use Show all devices below.
  4. Close the Divoom app first: only one app can hold the connection.
